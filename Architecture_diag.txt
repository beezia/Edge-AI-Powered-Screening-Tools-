### **Diagram Notes**

1. **Left Column: Sample Flow**

   * Simulates the lab workflow (image acquisition → filtering → curve preparation).
   * Fully synthetic, but visually represents real diagnostic processing.

2. **Right Column: Compute Stack**

   * CPU handles preprocessing, telemetry, and orchestration.
   * iGPU handles inference via ONNX Runtime + DirectML.

3. **Telemetry & UI**

   * Live metrics show **CPU %, iGPU %, latency, samples processed**.
   * Batch size and mode changes are reflected in real-time.

4. **Trade Show Modes**

   * Standard Lab: low batch, normal throughput.
   * Surge Mode: high batch, iGPU fully utilized.
   * CPU-Only Mode: iGPU disabled, shows latency increase.
